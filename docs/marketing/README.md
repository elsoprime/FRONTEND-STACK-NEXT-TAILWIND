# Marketing Docs (Separado de Backend)

Este espacio documenta unicamente flujos y activos de conversion del sitio marketing.

Principio:
- No mezclar con implementacion backend, contratos OpenAPI, RBAC o politicas de plataforma.
- No duplicar contenido de `docs/10-90_*`.

Contenido recomendado:
- CTA map de landing y secciones marketing.
- Convenciones visuales de conversion.
- Inventario de paginas y rutas de contacto comercial.
